# Security

Please report suspected vulnerabilities privately to [security@magicunicorn.tech](mailto:security@magicunicorn.tech). Do not open a public issue with exploit details, credentials, personal data, or recordings.

Include the affected commit or component, reproduction steps, impact, and any safe mitigation you know. Redact secrets from logs and attachments. If a PAT or other credential may have been exposed, revoke it immediately and rotate the affected deployment secret through its normal secret-management process.
